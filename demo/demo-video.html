Support Ticket Agent

AI-powered ticket classification, draft replies, WhatsApp + voice escalation

Built by Priyal Mehta

Node.js · BullMQ · PostgreSQL · FastAPI · LangGraph · OpenAI · Twilio

Step 1 — Create Ticket

Customer submits issue via Web or WhatsApp

Subject: Production database is down

Body: Database not responding since 10 AM. All users affected. Need immediate help.

Source: Web · Tier: Premium

Ticket enters Redis queue → background worker picks it up

Step 2 — AI Classification

Python LangGraph agent analyzes urgency and drafts reply

Bug Critical Needs Review

Confidence: 85%

The production database is down, affecting all users. Critical system failure requiring immediate attention.

Draft Response

Hi Customer, our team is aware of the production database issue and is investigating immediately. We aim to update you within 24 hours. Best regards, Support Team

Step 3 — Human Approval

Critical tickets require supervisor approval before sending

  • Dashboard shows Needs Review status
  • Agent reviews AI draft + reasoning
  • Approve → send reply (WhatsApp if applicable)
  • Reject → manual handling

Step 4 — Voice Escalation (Twilio)

For critical tickets, system calls owner for phone approval

Press 1 → approve and send WhatsApp reply

Press 2 → mark for manual handling
